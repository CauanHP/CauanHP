## 🛠️ Projetos Destacados

### 🗄️ [InMemoryDB](https://github.com/CauanHP/InMemoryDB-Advanced-CPP)
**Sistema de Banco de Dados em Memória**

Um banco de dados completo implementado do zero, demonstrando conceitos avançados de sistemas de dados.

**🔧 Tecnologias:** C++17, Threading, Estruturas de Dados Avançadas, ACID Transactions

**✨ Características:**
- Sistema de transações ACID com detecção de deadlocks
- Múltiplos tipos de índices (Hash, B-Tree, Bitmap)
- Engine de consultas SQL com parser e otimizador
- Gerenciamento de locks granular
- Sistema de logging avançado

**📊 Métricas:**
- ~5.000 linhas de código
- Suporte a 100+ transações concorrentes
- Performance: 100K+ operações/segundo

---

### 🎮 [GameEngine2D](https://github.com/CauanHP/GameEngine2D-Advanced-CPP)
**Engine de Jogos 2D com OpenGL**

Uma engine completa de jogos 2D, mostrando domínio em programação gráfica e arquitetura de sistemas.

**🔧 Tecnologias:** C++17, OpenGL 3.3+, GLFW, GLEW, GLM, Shaders GLSL

**✨ Características:**
- Pipeline de renderização moderno
- Sistema de shaders com hot reloading
- Arquitetura ECS (Entity-Component-System)
- Integração de física 2D e áudio espacial
- Gerenciamento inteligente de recursos

**📊 Métricas:**
- ~6.000 linhas de código
- Renderização de 10K+ sprites a 60 FPS
- Suporte a múltiplas plataformas

### 🔧 [SimpleCompiler](https://github.com/CauanHP/SimpleCompiler-Advanced-CPP)
**Compilador para Linguagem Customizada**

Um compilador completo implementando todas as fases de compilação, desde análise léxica até geração de código.

**🔧 Tecnologias:** C++17, Compiler Design, AST, Symbol Tables, Code Generation

**✨ Características:**
- Análise léxica com tokenização avançada
- Parser recursivo descendente com AST
- Análise semântica e verificação de tipos
- Geração de código para múltiplos targets
- Sistema de otimização e máquina virtual

**📊 Métricas:**
- ~4.000 linhas de código
- Suporte a 4 arquiteturas diferentes
- Compilação de 1M+ tokens/segundo
